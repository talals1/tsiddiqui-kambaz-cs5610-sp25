# Kambaz
Spring 2025

Course-long iterative homework for CS5610: Web Development at Northeastern University.

This is essentially a clone of Canvas, a popular learning management system, but built with the MERN stack. This frontend uses React, Bootstrap, Redux, React Router, Font Awesome, and Vite.

## Running
First ensure the backend and database are up and running.

To run the frontend, first run `npm install` then `npm run dev`.

## Demo
The frontend is live at https://tsiddiqui-kambaz.netlify.app/. 

To see a branch deploy, use the same URL prefixed with the `$BRANCH--`. For example, to see the final version of the application as completed in Assignment 6, please head to https://a6--tsiddiqui-kambaz.netlify.app/.
